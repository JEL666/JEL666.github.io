## Heap Sort

> `완전 이진 트리` 기반의 데이터 상태에 관계없이 일정한 속도를 가진 정렬 알고리즘

### 알고리즘
1. Heapify (MaxHeap)
   1. 부모와 자식 노드를 비교
   2. 만약 자식 노드가 부모 노드보다 크다면, 부모 노드와 교환 및 교환된 자식노드(전 부모노드)에 대해서 Heapify 진행
   3. 만약 부모 노드가 자식 노드보다 크거나 같다면, 종료

2. Heap 구조 구성
   1. 자식을 가진 후열의 노드부터 Bottom-up 방향으로 `Heapify` 진행

3. 최종 정렬
   1. root 노드를 가장 마지막 원소와 교환 (heap의 최댓값이 배열의 마지막에 위치하도록)
   2. heap 크기를 하나 줄인 채로, root 노드에 대한 heapify를 진행 (정렬된 원소를 제외한 나머지에 대해 Heap구조를 재구성)
   3. 그렇게 남은 Heap의 크기가 1이 될 때까지 1~2 반복

### 수도코드
```text
# 오름차순, MaxHeap으로 가정

A[]   # Heap Array

function heapify(arr, parent, heapSize)
    while true
        largest = parent
        left = parent * 2 + 1
        right = parent * 2 + 2

        if left < heapSize && arr[largest] < arr[left]  # left 노드와 크기비교
            largest = left

        if right < heapSize && arr[largest] < arr[right]  # right 노드와 크기비교
            largest = right

        if parent != largest   # 부모 노드보다 자식 노드가 더 크다면 swap 진행
            swap(arr[parent], arr[largest])
            parent = largest
        else                  # 자식 노드기 더 크지 않다면 종료
            break


function heapSort(arr)
    heapSize = A.length

    for i = heapSize/2-1 ~ 0  # 자식노드를 가진 노드들을 bottom-up 방향으로 각각 heapify
        heapify(arr, i, heapSize)

    for i = heapSize-1 ~ 1
        swap(arr[0], arr[i])        # 가장 큰 원소를 뒤로 보내고
        heapSize = heapSize - 1     # 뒤로 보낸 원소를 제외한 heap 크기로
        heapify(arr, 0, heapSize)   # heap 구조 재정렬

```

### 복잡도
**시간복잡도**
- 최선, 평균, 최악의 경우: `O(N*logN)`
  - 힙 구조 구성: `O(N)`
  - 최댓값 추출 및 Heap 구조 재구성: `O(N*logN)` = `O(N)` * `O(logN)`
    - N개의 노드를 제거하면서 `O(logN)` 단계의 `Heapify` 실행

**공간복잡도**
- 일반적인 경우: `O(1)`
  - in-place
  - 단, 재귀로 구현할 경우 함수 스택의 크기인 `O(logN)`

### 장단점
**장점**
- 최악이어도 시간복잡도 `O(N*logN)` 보장
- 추가공간 X (in-place)

**단점**
- tree구조를 배열로 표현하니 캐시 지역성이 떨어짐
(상대적으로 지역성이 낮아 quick sort보다 평균적으로 느림)
- Unstable Sort
- Divide and conquer를 사용하는 Quick, Merge에 비해 병렬화가 어려움 (순차적인 진행)


### `Merge Sort`와 `Heap Sort`에 대한 생각
반복문과 LinkedList로 구현한 `Merge Sort`와 `Heap Sort`의 차이

공통점
 - 속도가 안정적
 - 지역성이 낮음 (LinkedList vs. Tree 구조 배열)

차이점
 - LinkedList, Array
 - Stable Sort(Merge), Unstable Sort(Heap)

그렇다면 실제 테스트 전에 성능적인 면에서 예측해보자면
 - 데이터의 수가 적을수록 배열인 Heap Sort가 유리
 - 한 데이터의 크기가 클수록 배열을 직접 Swap하는 것이다보니 LinkedList의 주소값 교환보다 비용이 커 Merge Sort가 유리
