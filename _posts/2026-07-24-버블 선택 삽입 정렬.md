가장 기본적인 정렬 알고리즘들인 `Bubble Sort`, `Selection Sort`, `Insertion Sort`를 정리함

## Bubble Sort
> 인접한 두 원소를 `swap`

### 알고리즘 과정
1. 정렬되지 않은 구간을 선택
2. 선택된 구간에서 차례로 다음을 반복
   - 인접한 두 원소를 비교하여 swap
3. 정렬되지 않은 구간이 없어질 때까지 1번으로 이동

### 수도코드
```
# 오름차순 정렬이라고 가정

for i = n-1 -> 0     # 정렬되지 않은 구간(i)을 선택
    for j = 0 -> i-1     # 그 구간 내에서 비교 및 swap을 반복
        if A[j] > A[j+1]
            swap(A[j], A[j+1])
```

### 복잡도
시간복잡도
- n^2번의 비교와 최악의 경우 n^2의 `swap`이 발생하므로 `O(n^2)`
  
공간복잡도
- 추가적인 공간이 필요하지 않아 `O(1)`

### 장단점
**장점**
 - 구현하기 간단함

**단점**
 - 비교와 `swap`이 많이 발생해 비효율적임

## Selection Sort
> 극값인 원소 하나를 선택

### 알고리즘 과정
1. 정렬되지 않은 구간을 선택
2. 그 구간 내에서 극값(최댓값 혹은 최솟값)을 선택하여 구간의 끝과 `swap`
3. 정렬되지 않은 구간이 없어질 때까지 1번으로 이동

### 수도코드
```
# Max값을 선택하여 오름차순으로 정렬하는 것으로 가정
for i = n-1 -> 0       # 정렬되지 않은 구간(i)을 선택
{
    max_index = 0
    for j = 0 -> i       # 그 구간(i) 내에서 최댓값을 찾아 선택
        if A[max_index] < A[j]
            max_index = j

    swap(A[max_index], A[i]);   # 한 쪽으로 위치시켜 정렬
}
```

### 복잡도
시간복잡도
- 매 단계마다 정렬되지 않은 구간 전체를 탐색하므로 `O(n^2)`
  
공간복잡도
- 추가적인 공간이 필요하지 않아 `O(1)`

### 장단점
**장점**
 - 정렬 과정이 단순하며, 다른 두 정렬과 비교하여 상대적으로 swap 횟수가 적음

**단점**
 - 정렬 상태와 관계없이 비교 횟수가 일정함 (성능 향상이 어려움)
 - Unstable Sort

## Insertion Sort
> 정렬된 구간에서 올바른 위치에 삽입

### 알고리즘 과정
1. 정렬된 구간의 다음 원소 하나를 선택
2. 선택한 원소를 정렬된 구간 사이에 삽입하여 재정렬
3. 모두 정렬될 때까지 1번을 반복

### 수도코드
```
# 오름차순 정렬로 가정

for i = 1 -> n-1     # 정렬된 구간의 다음 원소(i)를 선택
    key = A[i]
    j = i-1

    while j >= 0 and key < A[j]    # 원소(i)가 적절한 위치에 올 때까지 shift 반복
        A[j+1] = A[j]
        j = j-1 

    A[j+1] = key    # 원소(i)를 적절한 위치에 삽입
```

### 복잡도
시간복잡도
- 최악의 경우 원소 선택마다 정렬된 구간을 모두 `shift` 해야하므로 `O(n^2)`
- 거의 정렬되어 있는 경우에 `O(n)`
  
공간복잡도
- 추가적인 공간이 필요하지 않아 `O(1)`

### 장단점

**장점**
- 거의 정렬되어 있는 경우에 이동 횟수가 적음 (원소 이동이 적으므로)
  
(여담으로 이 장점과 참조 지역성 등을 고려하여 [`Introsort`](https://en.wikipedia.org/wiki/Introsort)는 작은 구간에 대해서 삽입정렬을 사용한다.)

**단점**
- 범위가 커질수록 원소를 이동시켜야 하는 크기가 커짐
